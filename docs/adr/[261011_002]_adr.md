## ADR-1. 링크는 인라인 헬퍼 `link(주소, 글자)`로 쓴다

**상태**: 확정, 구현됨

**결정**
- `link("https://…")`는 주소를 그대로 보여 주는 링크이고, `link("https://…", "다운로드")`는 글자를 보여 준다. 클릭하면 새 탭에서 열린다(`target="_blank"`, `rel="noopener noreferrer"`).
- 밑줄로 링크임을 알린다. 색은 마스터 tokens의 `--link-color`이고, 정하지 않으면 주변 글자색을 따른다(필수 토큰으로 두지 않는다).
- 이유: 수강생이 슬라이드(HTML)에서 자료 주소를 바로 열 수 있게 한다. 문장 안의 서식이라 `chip()`, `em()`처럼 인라인 헬퍼로 둔다.

**결과**
- 미리보기와 HTML export 모두 같은 `<a>`로 그린다. 위치를 정한 요소는 `.free > *`에서 마우스를 받으므로 클릭할 수 있다.

---

# 강의에 필요한 수정

**없다.** `link()`는 새로 더한 기능이라 쓰지 않는 기존 강의는 영향이 없다([261008_003] ADR-22).

**확인한 방법**(2026-10-11): 이 ADR(과 [261011_003]의 화살표 머리)이 들어가기 전(`main`, `e37d166`)과 후를 따로 체크아웃해 `sample`, `sample2`, `default-course`의 슬라이드 34장을 내보내기용 렌더링으로 그려 Chrome(1920×1080) 캡처를 픽셀 단위로 비교했다. 34장 모두 같았다. 슬라이드 HTML의 본문도 모두 같았고, `sample`만 마스터에 더한 `--link-color`가 슬라이드 바깥 `style`에 들어가 달랐다. `npm run typecheck`는 `sample`, `sample2`, `default-course`, `sds-agent-development` 모두 통과했다.

- 링크 색을 정하려면 마스터 tokens에 `--link-color`를 더한다(`sample`은 `#0563C1`). 정하지 않아도 오류는 없고 주변 글자색에 밑줄만 그려진다.
- 확인하지 못함: Chrome 외 브라우저, 다른 강의 저장소.
