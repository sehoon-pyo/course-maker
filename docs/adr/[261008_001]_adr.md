# ADR [261008_001]: 순서는 상위 meta의 배열, 폴더 이름 규칙, 숨김 슬라이드

## ADR-1. 순서는 모두 상위 `meta.ts`의 배열이 정한다

**상태**: 확정, 구현됨 ([261007_002] ADR-2의 "chapter와 section의 순서는 폴더 이름의 번호가 정한다"를 대체함. chapter 바로 아래의 `head`, `tail` 슬라이드는 [`[261008_002]_adr.md`](./[261008_002]_adr.md) ADR-2로 더해짐)

**맥락**
slide는 section `meta.ts`의 `slides` 배열이, chapter와 section은 폴더 이름의 번호(`ch.N_`, `sec.N_`)가 순서를 정했다. 번호가 폴더 이름에 있으면 항목을 끼워 넣을 때 뒤의 폴더 이름을 모두 바꿔야 하고, 번호가 겹치거나 빠지면 순서가 우연히 정해진다.

**결정**
- 순서는 `course → chapter → section → slide` 모두 상위 `meta.ts`의 배열이 정한다.
  ```ts
  // courses/{강의}/meta.ts
  export default { title: "샘플 강의", chapters: ["ch.1_intro", "ch.2_control"] } satisfies CourseMeta;

  // courses/{강의}/ch.1_intro/meta.ts
  export default { title: "1장", sections: ["sec.1_variable", "sec.2_function"] } satisfies ChapterMeta;

  // courses/{강의}/ch.1_intro/sec.1_variable/meta.ts
  export default { title: "변수", slides: ["sl.1_title", { id: "sl.2_extra", hidden: true }] } satisfies SectionMeta;
  ```
- 폴더 이름의 번호는 순서의 기준이 아니다.
- 화면의 section 번호(`SECTION n`, [261007_004] ADR-1)는 chapter 안의 이 배열 순서이다.

**결과**
- 항목을 끼우거나 순서를 바꿀 때 배열만 고치면 되고 폴더를 옮기지 않는다.
- 새 항목을 만들면 폴더와 배열을 둘 다 고쳐야 한다. 어긋나면 ADR-3의 경고가 알려 준다.
- 기존 강의의 `meta.ts`는 `chapters`, `sections`를 추가해야 읽힌다(도구가 바뀌면 강의가 깨질 수 있다는 [261007_003] ADR-2의 주의가 여기에도 해당한다).

## ADR-2. 폴더 이름의 번호 접두사는 선택이다

**상태**: 확정, 구현됨

**결정**
- `ch.1_intro`, `sec.1_variable`, `sl.1_title`처럼 `접두사.번호_이름`으로 써도 되고, `ch.intro`처럼 번호 없이 `접두사.이름`으로, 접두사 없이 `intro`로 써도 된다.
- 화면에 보이는 이름은 접두사(`ch.`, `sec.`, `sl.`, 번호와 `_`)를 뗀 부분이다.
- 번호는 정리용이며 배열과 어긋나도 화면 순서에는 영향이 없다.

**결과**
- URL 해시(`#/{강의}/{chapter}/{section}/{slide}`)는 폴더 이름 그대로이다. 접두사나 번호를 바꾸면 해시가 바뀐다.
- 용어사전의 폴더 이름 표기(`ch.N_{이름}` 등)는 권장 형식이다.

## ADR-3. 배열과 폴더가 어긋나면 경고한다

**상태**: 확정, 구현됨 (slide에 이미 있던 동작을 chapter와 section으로 넓힘)

**결정**
- 배열에 있지만 폴더(`meta.ts`)가 없는 항목은 경고하고 건너뛴다.
- 폴더는 있지만 배열에 없는 항목은 경고하고 표시하지 않는다.
- 배열에 같은 이름이 둘 이상이면 첫 번째만 쓰고 경고한다.

**결과**
- 경고는 브라우저 콘솔에 나온다. 항목을 숨기는 용도로 배열에서 빼지 않는다(숨김은 ADR-4).

---

## ADR-4. 숨김 슬라이드

**상태**: 확정, 구현됨 (뷰어의 표시, 이전/다음으로 오가는 것은 구현됨. 숨김 슬라이드를 `n / 전체`에 포함하는 부분과 하단 안내는 [`[261008_002]_adr.md`](./[261008_002]_adr.md) ADR-1로 대체됨: 숨김은 번호를 매기지 않고 하단은 `숨김 / N`이며 안내문은 없다. export에서 제외하는 부분은 export를 만들 때 한다)

**결정**
- section `meta.ts`의 `slides` 항목을 문자열 대신 `{ id, hidden: true }`로 쓰면 숨김 슬라이드이다. 문자열은 `{ id }`와 같다(숨기지 않음).
- **뷰어(미리보기)에서는 숨김 슬라이드도 보인다.** 사이드바에서 "숨김" 표시와 함께 흐리게 보이고, 현재 슬라이드가 숨김이면 하단에 안내가 나온다. 이전/다음과 `n / 전체`에도 포함된다.
- HTML, PPTX, PDF로 내보낼 때는 숨김 슬라이드를 제외한다.
- 숨김의 표시는 슬라이드 파일이 아니라 `slides` 항목에 둔다.

**결과**
- export가 아직 없어서 "내보낼 때 제외"는 export를 만들 때 구현한다.
- PowerPoint의 슬라이드 숨기기와 같은 개념이다.
- `hidden` 외의 슬라이드 속성(예: 발표자 메모)은 같은 객체 항목에 추가할 수 있으나 이 ADR에서 정하지 않는다.
