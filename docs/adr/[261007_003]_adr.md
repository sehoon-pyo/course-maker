## ADR-1. 사용 방식: 로컬 사용, 동적 수정은 파일 수정

**상태**: 확정 ([261007_002] ADR-5의 "서비스 형태"와 "agent 연동은 나중에" 부분을 대체)

**결정**
- **서비스로 배포하지 않는다.** 사용자는 **레포지토리를 내려받아 로컬에서** 사용한다.
- AI(Claude Code 등)가 로컬 저장소의 TSX를 직접 고치는 방식이 기본 사용 방식이다.
- **"동적 수정"은 파일 수정을 뜻한다.** 파일을 고치면 미리보기에 바로 반영되는 방식(Vite HMR)으로 충분하며, 화면에서 직접 고쳐 TSX에 저장하는 기능은 만들지 않는다.
- 슬라이드의 `text` 객체는 단순한 값(문자열, 배열, `badge()` 같은 헬퍼 호출)으로만 두고 로직을 섞지 않는다.

**결과**
- AI가 만든 TSX를 서버에서 실행하는 보안 문제, 웹 서버, 인증, 호스팅, 다중 사용자는 고려하지 않는다.

## ADR-2. 강의는 강의별 별도 저장소로 관리

**상태**: 확정

**결정**
- `courses/{강의}` 폴더마다 자기 `.git`을 가진 **별도 저장소**로 관리한다. `course` = 하나의 전체 강의 = 하나의 저장소.
- 도구 저장소의 `.gitignore`는 `courses/*`를 무시하고 예제만 추적한다(`!courses/sample/`, `!courses/sample2/`).
- 도구 저장소를 `git pull`로 업데이트해도 강의 파일과 섞이지 않고, 강의 저장소는 비공개로 둘 수 있다.

**결과**
- 강의 저장소의 슬라이드가 도구의 API(`@/elements` 등)에 의존하므로 도구가 바뀌면 강의가 깨질 수 있다. API 버전 관리 방법은 정하지 않았다.
- 대안으로 검토했으나 채택하지 않은 것: git submodule, 저장소 밖 폴더 지정(`COURSES_DIR`).

## ADR-3. 슬라이드 마스터 구조

**상태**: 확정 (구현은 layout을 정할 때 함께 한다)

**결정**
- **마스터는 course 단위로 고른다.** `courses/{강의}/meta.ts`의 `master` 필드(선택 사항)로 마스터 id를 지정하고, 없으면 `default`를 쓴다. chapter, section, slide 단위로 마스터를 바꾸지 않는다.
- 도구가 제공하는 마스터는 `src/masters/{id}/index.tsx`에 둔다. 폴더 이름이 마스터 id이고 `import.meta.glob`으로 자동 등록한다. `_`로 시작하는 폴더(`_shared`)는 등록하지 않고 공용 부품을 둔다.
- **강의 전용 마스터를 지원한다.** `courses/{강의}/masters/{id}/index.tsx`.
- 마스터 id 조회 순서: **① `courses/{강의}/masters/{id}` → ② `src/masters/{id}`** → 둘 다 없으면 사용 가능한 마스터 목록과 함께 오류. 같은 id가 양쪽에 있으면 강의 전용이 우선한다.
- 마스터는 `extendMaster(...)`로 다른 마스터를 확장할 수 있다.

**결과**
- 강의 하나는 마스터 하나만 쓰므로 chapter 하나가 되는 단일 HTML, PPTX, PDF에도 마스터가 하나만 들어간다.
- 마스터와 layout은 아직 코드로 만들지 않았다. `defineMaster`, `extendMaster` 등의 API는 layout의 모양과 함께 확정한다.

## ADR-4. 미리보기 창 구성

**상태**: 확정 (구현됨)

**결정**
- **사이드바**는 접고 펼 수 있고(상단 바의 ☰ 버튼), 상태는 `localStorage`에 저장하되 저장소를 못 쓰는 환경에서도 동작한다.
- 사이드바는 **선택된 chapter의 목차**(section → slide)를 보여 준다. 다른 chapter의 목차는 chapter 콤보박스로 바꾼다.
- **상단 네비게이션 바**에는 사이드바 토글, 현재 위치, 오른쪽의 항목 영역을 둔다. 오른쪽 영역에 **강의 선택 콤보박스**와 **chapter 선택 콤보박스**를 둔다.
  - 강의를 고르면 그 강의의 첫 슬라이드로, chapter를 고르면 그 chapter의 첫 슬라이드로 이동한다.
  - chapter 콤보박스에는 선택된 강의의 chapter만 나온다.
- 현재 위치는 **`chapter / section / slide` 순서**로 표시한다(강의 이름은 콤보박스에 있어 제외).
- 샘플 강의로 `courses/sample`(chapter 2개, slide 11장)과 `courses/sample2`(chapter 2개, slide 6장)를 도구와 함께 둔다.

**결과**
- 이전/다음 버튼, 방향키, `n / 전체` 표시의 기준(강의 단위인지 chapter 단위인지)은 아직 정하지 않았다. 현재는 강의 단위이다.
