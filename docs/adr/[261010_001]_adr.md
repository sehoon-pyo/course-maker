- 날짜: 2026-10-10
- 관련 이슈: #5(내보내기 버튼과 선택 모달), #6(단일 HTML export 구현)
- 이전 ADR: [`[261007_002]_adr.md`](./[261007_002]_adr.md), [`[261008_003]_adr.md`](./[261008_003]_adr.md)
- 범위: 결정된 사항만 기록한다. 구현했다(2026-10-10). PPTX와 PDF 생성은 아직 없다.

## ADR-1. 내보내기는 상단 바의 버튼과 모달로 하고, 결과는 강의 폴더의 `export/{연월일시분초}/`에 저장한다

**상태**: 확정, 구현됨

**결정**
- 미리보기 상단 바에 내보내기 버튼을 둔다. 누르면 모달이 열리고 **course 하나**, 그 course의 **chapter(여러 개)**, **파일 형식(HTML, PPTX, PDF. 여러 개)**을 고른다.
- 저장 위치는 `courses/{course}/export/{연월일시분초}/`이다. 시각은 14자리(예: `20261010172130`)이고 실행할 때마다 새 폴더를 만든다. 같은 초에 다시 실행하면 덮어쓰지 않고 오류를 낸다.
- 파일 이름은 `CHAPTER_<No>_<파일제목>.<확장자>`이다. `<No>`는 course의 `chapters` 배열 순서(1부터)이고 chapter 수의 자릿수에 맞춰 0으로 채운다(chapter가 9개 이하면 `1`, 10개 이상이면 `01`). `<파일제목>`은 chapter `meta.ts`의 `title`이고 파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > |`와 제어 문자)는 `_`로 바꾼다.
- `export/`는 git이 추적하지 않는다(`.gitignore`의 `courses/*/export/`).
- 브라우저는 로컬 폴더에 쓸 수 없으므로 개발 서버의 플러그인(`vite-export.ts`)이 폴더를 만들고 파일을 쓴다. 개발 서버에서만 동작한다.

**결과**
- 요청은 JSON만 받고 강의 이름은 `courses/` 아래에 `meta.ts`가 있는 폴더만 받는다.
- 파일을 쓰기 전에 모두 만들어 두므로 중간에 실패해도 빈 폴더나 일부 파일이 남지 않는다.
- 선택한 형식 중 아직 만들 수 없는 PPTX, PDF는 건너뛰고 모달에 알린다.

## ADR-2. 단일 HTML은 서버에서 슬라이드를 HTML로 그려 한 파일로 묶는다

**상태**: 확정, 구현됨 ([261007_002] ADR-3의 "`vite-plugin-singlefile` 같은 방식으로 만들 예정"을 대체함. 뷰어는 [261008_003] ADR-1을 따름)

**결정**
- 개발 서버가 `ssrLoadModule`로 슬라이드 TSX와 마스터를 Node에서 불러오고, 미리보기와 같은 `MasterFrame`으로 `renderToStaticMarkup`을 호출해 슬라이드마다 HTML 조각을 만든다(`src/export/renderChapter.tsx`). 숨김 슬라이드는 뺀다. 브라우저 API를 쓰는 요소는 이 방식에서 동작하지 않으므로 export가 읽는 코드에서 쓰지 않는다.
- `vite-export-html.ts`가 조각들을 HTML 문서 하나로 묶는다.
  - CSS는 `src/slide.css`를 파일 안에 넣고, 폰트(NanumSquare R, B)는 base64로 넣는다.
  - 이미지 경로(`/courses/…/logo.svg` 등)는 파일을 읽어 data URI로 바꾼다. 못 찾거나 외부 경로가 남으면 오류로 멈춘다.
  - 슬라이드를 한 장씩 보이고 창 크기에 맞춰 비율을 유지해 줄이는 작은 스크립트를 넣는다. 이동은 **방향키(← →)만** 지원한다(React와 미리보기 UI는 넣지 않는다).
- 미리보기와 내보내기가 같은 CSS를 쓰도록 `styles.css`를 둘로 나눴다. 폰트와 슬라이드 요소의 CSS는 `src/slide.css`, 미리보기 창(사이드바, 상단 바, 모달)의 CSS는 `src/styles.css`이다(`@import "./slide.css"`).

**결과**
- 같은 입력으로 두 번 내보낸 파일이 바이트 단위로 같았다(2026-10-10 확인, sample의 chapter 2개).
- 파일 하나가 약 2MB이다. 대부분 폰트(두 파일 합쳐 약 1.4MB를 base64로 넣음)이다.
- 확인함: sample `ch.1_intro`, `ch.3_master`를 내보내 HTTP로 열었을 때 외부 요청이 없고, 폰트 400/700이 로드되고, 방향키로 이동하고 끝에서 멈추며, 숨김 슬라이드가 빠졌다(`ch.3_master` 9장 중 8장). 미리보기와 눈으로 비교한 것은 첫 장뿐이다.
- 확인하지 못함: `sample2`의 HTML 파일, chapter 여러 개를 한 번에 내보낸 결과의 모든 슬라이드의 모양, 파일을 `file://`로 직접 연 동작(시험 도구가 `file:`을 막아 HTTP로 열었다).
- 강의에 필요한 수정은 없다. 강의 전용 요소가 렌더링 중에 브라우저 API(`window`, 크기 측정 등)를 쓰면 내보내기가 실패하거나 다르게 그려질 수 있다.
