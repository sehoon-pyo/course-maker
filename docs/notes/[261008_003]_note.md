### 4. 사람이 눈으로 확인할 것

- 샘플의 모양: `sample`의 기존 17장의 색, 띠, 글자 크기 변화, 새 샘플 `ch.3_master`와 숨김 슬라이드. (plan 5번)
- 네 layout이 기존 PPTX와 비슷한 인상인지. 렌더링해서 비교한 적이 없고 좌표와 색은 XML 값으로만 대조했다.
- 로고, `PromptBox`, `Chip`의 모양.
- 그림자와 자유형 도형의 CSS 표현이 PPTX와 다르게 보이는지.
- 이번에 새로 확인할 것(2026-10-08):
  - 글로우(네온)의 번짐이 PowerPoint와 같은지. 값(반경, 색, 알파)은 PPTX 그대로이고 번지는 모양은 다를 수 있다.
  - 터미널과 파일 svg가 원본 이미지와 같은지. 눈으로 맞춘 것이라 픽셀 단위로는 다르다. claude는 원본의 픽셀 좌표를 읽어 그렸다.
  - 뱃지 정렬 0.10em. 한글 중심선과 0.5px 차이이고 숫자와 영문 소문자가 섞인 줄에서도 어색하지 않은지.
  - `tail` 슬라이드(`sl.9_progress`)의 모양.
- claude 캐릭터는 제3자의 것일 수 있다. 사용자가 PPTX에서 쓰도록 했고, 도구의 `src/`가 아니라 sample 강의의 `assets/`에 있다.

기록의 서술은 고치지 않는 규칙이므로 아래는 목록으로만 둔다. 정리할지는 따로 정한다.

### 6. 이미 해결되어 뺀 것

- 폰트 라이선스: 무료로 확인했다. 폰트 파일 커밋과 납품 시 동봉에 제약이 없다.
- `layout`의 종류: 4개(`title`, `content`, `title-only`, `toc`)로 정했다.
- 마스터 적용 방식(`MasterFrame`과 context), 목차의 항목 슬롯(`list` 슬롯)과 자동 채움.
- `sectionLabel`(기본 `SECTION`).
- 번호와 이동의 기준: chapter 기준으로 정했다(ADR 261008_002 ADR-1).
- 요청 2(강의, chapter 드롭다운을 사이드바로): 취소했다.
- 뱃지 정렬값(0.10em), 칩과 프롬프트 박스의 아이콘, 글로우, 도장.
