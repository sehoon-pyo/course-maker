BRIEFING 261010_005 · 강의 템플릿

강의 템플릿(default-course) 만들 준비

저장소와 문서를 읽고 정리했습니다. 코드와 강의 폴더는 아직 만들거나 고치지 않았습니다. 아래 결정이 정해지면 시작합니다.

확인한 것

  • 템플릿 방식은 이미 정해져 있습니다 (docs/adr/[261008_003]_adr.md ADR-20). 강의의 초깃값은 별도의 default-course template 저장소이고, 사용자가 courses/ 안에서 이것으로 자기 강의 저장소를 만들어 clone합니다. 복사한 시점에 고정되고 이후 변경은 받지 않습니다.
  • 마스터는 템플릿에 들어갑니다 (ADR-21). 도구(src/masters/)는 마스터를 제공하지 않고, 기본 마스터 default는 강의의 masters/default/에 둡니다.
  • 재료는 courses/sample/에 있습니다:
    • meta.ts (강의 제목, chapters)
    • masters/default/index.tsx (146줄)와 assets/logo.png, logo.svg
    • elements/index.ts (도구 요소를 export * from "@/elements"로 다시 내보내고 강의 요소를 더함)와 칩 3개
    • ch.N_이름/sec.N_이름/sl.N_이름/index.tsx 폴더 규칙, 대제목 슬라이드 예시(Slide layout="title" + Title + Paragraph, 문구는 맨 위 text 객체)
  • courses/ 안에는 sample과 sample2만 있습니다. ADR-20이 말하는 임시 courses/default-course/는 이 작업 폴더에는 없습니다. 이 저장소는 courses/*를 무시하고 sample, sample2만 추적합니다.
  • sample2는 다른 마스터(plain, 55줄)와 강의 전용 Bullets, CodeChip 요소를 가진 두 번째 예시입니다.
  • CLAUDE.md가 바뀐 것을 반영했습니다. 내보내기 모달과 courses/{강의}/export/{연월일시분초}/ 빈 폴더 만들기까지 구현되어 있고, export/는 git이 추적하지 않습니다.

확인하지 못한 것

  • default-course template 저장소를 만드는 시점과 이름: ADR-20이 "정하지 않았다"고 적어 둔 항목입니다.
  • GitHub에 template 저장소를 만들 수 있는지: gh 로그인 상태와 권한은 확인하지 않았습니다.
  • sample 마스터의 내용(146줄)과 sample이 쓰는 로고가 템플릿에 그대로 맞는지는 읽어 보지 않았습니다.
  • docs/plan.md, README.md 2번과 10번(로드맵)에 템플릿 항목이 있는지는 읽지 않았습니다.
  • 템플릿 강의가 도구의 현재 API로 npm run typecheck와 미리보기를 통과하는지는 만들어 봐야 알 수 있습니다.

제안하는 최소 골격

default-course/
├─ meta.ts                      제목, chapters: ["ch.1_..."]
├─ masters/default/index.tsx    sample의 default 마스터 복사
│  └─ assets/logo.*
├─ elements/index.ts            export * from "@/elements"  (강의 전용 요소는 비워 둠)
├─ assets/                      비어 있음 (.gitkeep)
├─ .gitignore                   export/
└─ ch.1_.../
   ├─ meta.ts                   head: ["sl.1_title"], sections: ["sec.1_..."]
   ├─ sl.1_title/index.tsx      대제목 (layout="title")
   └─ sec.1_.../sl.1_.../index.tsx   본문 (layout="content")
