  • 내보내기 버튼은 PPTX, PDF도 함께 쓰는 UI라서, 이 이슈에서 어디까지 만들지를 아래 결정 2로 남겼습니다.

단일 HTML export 구현

featarea:exportarea:previewmilestone: 단일 HTML export

배경

최종 강의자료(HTML)는 chapter 하나가 파일 하나인 단일 HTML로 배포한다. 지금은 미리보기 창만 있고 내보내기가 없어 강의자료를 배포할 수 없다. PDF export(Chrome headless 인쇄)도 이 HTML을 입력으로 쓴다.

원하는 동작

  • 미리보기 상단 바에 내보내기 버튼을 추가한다. 누르면 형식을 고르는 체크박스(HTML, PPTX, PDF)가 나온다.
  • HTML을 선택하면 chapter 하나의 슬라이드가 든 HTML 파일 하나가 만들어진다. JS, CSS, 폰트, 이미지는 파일 안에 포함하고 외부 파일에 의존하지 않는다.
  • 뷰어는 방향키 이동만 포함한다. 축소 표시와 이전/다음 버튼은 넣지 않는다. 미리보기 전용 UI(사이드바, 상단 바)는 제외한다.
  • 숨김 슬라이드(hidden: true)는 내보낼 때 뺀다. 미리보기에서는 계속 보인다.
  • PPTX, PDF 체크박스를 실제로 동작시키는 일은 각 마일스톤의 이슈에서 한다.

  • 폰트를 포함한 HTML 용량: 노트에 "약 2MB 안팎 예상"뿐이고 측정한 적이 없습니다.
  • 현재 상단 바(src/preview/)의 구조: 이번에는 코드를 읽지 않았습니다.
