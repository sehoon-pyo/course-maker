올라갈 모습

단일 HTML export 구현

featarea:exportmilestone: 단일 HTML export

배경

최종 강의자료(HTML)는 chapter 하나가 파일 하나인 단일 HTML로 배포한다. 지금은 미리보기 창만 있고 내보내기가 없어 강의자료를 배포할 수 없다. PDF export(Chrome headless 인쇄)도 이 HTML을 입력으로 쓴다.

원하는 동작

  • chapter를 지정해 내보내면 그 chapter의 슬라이드가 든 HTML 파일 하나가 만들어진다. JS, CSS, 폰트, 이미지는 파일 안에 포함하고 외부 파일에 의존하지 않는다.
  • 뷰어는 방향키 이동만 포함한다. 축소 표시와 이전/다음 버튼은 넣지 않는다. 미리보기 전용 UI(사이드바, 상단 바)는 제외한다.
  • 숨김 슬라이드(hidden: true)는 내보낼 때 뺀다. 미리보기에서는 계속 보인다.
  • 번호는 chapter 기준으로 1부터 이어지고 숨김 슬라이드는 세지 않는다.

관련 문서

  • docs/adr/[261008_003]_adr.md (ADR-1 뷰어, ADR-2 출력 단위, ADR-4 숨김 슬라이드)
  • docs/adr/[261008_002]_adr.md (ADR-1 chapter 기준 번호)
  • docs/notes/[261008_003]_note.md (1, 2, 4번 항목)

확인한 것과 확인하지 못한 것

확인함: chapter 단위 파일(ADR 261007_002), 뷰어는 방향키만(ADR-1), 숨김 제외(ADR-4), 번호 기준(ADR 261008_002), 미리보기 전용 UI 제외(노트 261007_002).

확인하지 못함 (본문에 단정하지 않았습니다)

  • 내보내는 방법: 명령어, chapter 지정 방식, 출력 위치는 문서에 없습니다. vite-plugin-singlefile을 쓸 예정이라고만 있고 정확한 옵션은 구현 때 확인한다고 되어 있습니다. 본문의 "chapter를 지정해 내보내면"은 이 점을 구체화하지 않은 표현입니다.
  • 폰트 base64 포함 시 용량: 노트에 "약 2MB 안팎 예상"이라는 예상치뿐이고 측정한 적이 없습니다.
  • 단일 HTML에서 Ctrl + ←/→(chapter 이동)는 의미가 없을 텐데, 문서에 따로 정해진 것이 없습니다.
