내보내기 버튼과 선택 모달 이슈 본문

"내보내기 버튼만 일단 만든다"는 범위로 본문을 다시 썼습니다. 이슈는 아직 올리지 않았습니다. 코드도 건드리지 않았습니다.

이전 초안과 달라진 점

  • 범위를 버튼 + 모달(course 선택, chapter 체크박스, 형식 체크박스)로 좁혔습니다. HTML, PPTX, PDF 파일을 실제로 만드는 일은 형식별 이슈로 남깁니다.
  • 저장 위치 규칙을 넣었습니다: courses/{course}/export/{연월일시분초}/ 아래에 선택한 형식의 파일을 같이 저장합니다.
  • 그래서 "단일 HTML export 구현"(A1)과 이 이슈를 둘로 나누는 안을 제안합니다(결정 3).

올라갈 모습

미리보기에 내보내기 버튼과 선택 모달 추가

featarea:previewarea:exportmilestone: 결정 3

배경

강의자료를 내보내는 기능이 없다. HTML, PPTX, PDF 내보내기를 각각 구현하기 전에, 무엇을 어디에 내보낼지 고르는 공통 진입점과 저장 위치 규칙이 필요하다.

원하는 동작

  1. 미리보기 상단 바에 내보내기 버튼을 둔다.
  2. 버튼을 누르면 모달 팝업이 열린다.
    • course를 고른다.
    • 고른 course의 chapter를 체크박스로 고른다(여러 개 선택 가능).
    • 파일 형식을 체크박스(HTML, PPTX, PDF)로 고른다(여러 개 선택 가능).
  3. 저장 위치는 courses/{course}/export/{연월일시분초}/이다. 실행할 때마다 시각 폴더를 새로 만들고, 선택한 형식의 파일을 그 아래에 같이 저장한다.

이 이슈의 범위는 버튼과 모달, 선택 값을 받아 저장 위치를 정하는 데까지이다. 형식별 파일 생성은 각 형식의 이슈에서 한다.

관련 문서

  • docs/notes/[261008_003]_note.md (1번 항목)

  • ☐ npm run typecheck 통과

  • ☐ README, glossary.md, CLAUDE.md 갱신 (현황과 로드맵 포함)

확인한 것과 확인하지 못한 것

확인함: 위 동작은 사용자의 요청 그대로입니다. chapter 하나가 파일 하나라는 출력 단위는 ADR-2에 있습니다.

확인하지 못함 (본문에 단정하지 않았습니다)

  • 시각 폴더 이름의 자릿수: 요청의 예시 202610101721은 12자리(연월일시분)인데 "연월일시분초"라고 하셨습니다. 초까지면 14자리(20261010172130)입니다(결정 1).
  • 파일을 폴더에 쓰는 방법: 브라우저는 임의 폴더에 파일을 쓸 수 없어서 개발 서버(Vite) 쪽에서 저장해야 할 것으로 보입니다. 문서에 정해진 것이 없고 확인하지 못했습니다.
  • 파일 이름: chapter마다 파일이 하나이므로 시각 폴더 안의 파일 이름 규칙이 필요합니다. 정해진 것이 없습니다(결정 4).
  • export/ 폴더의 git 추적: 강의는 별도 저장소라 산출물이 커밋될 수 있습니다. 강의 저장소의 .gitignore에 넣을지 정해진 것이 없습니다(결정 5). CLAUDE.md는 PDF와 HTML을 "출력물이며 직접 고치지 않는다"고만 규정합니다.
  • 현재 상단 바 코드(src/preview/)는 이번에도 읽지 않았습니다.
